# Edible Estate v0.1 – PRD (Summary)

## Objective
- Standardize on the custom overlay map stack (not Mapbox Draw).
- After address lookup and centering, draw parcel boundaries in the Earthworks & Water tab (must be completed before any other drawings).
- Integrate real NRCS/USDA soils for the parcel area (server-side proxy) and surface it in the planner.
- Introduce horizontal tabs in the Map Planner: Climate; Earthworks & Water; Zones, Structures & Paths; Plants & Animals.
- Persist designs per project in Supabase per provided schema context.

## Success Metrics
- 90% of users create a project, enter an address, and reach a centered map; can draw the parcel in Earthworks & Water within 10s of map load.
- Users can draw+save a parcel and at least one object, then reload with 100% fidelity.
- Questionnaire flows unaffected (no regressions).

## Tabs and Tools (v0.1)
- Climate
  - Content: "Coming Soon" and a link to https://weatherspark.com/
- Earthworks & Water
  - Options/Overlays: Contours/terrain toggle available after coordinates are set.
  - Soils: Add soil types as polygons that fill the selected parcel (clip to parcel; coincident boundaries to avoid gaps) with hover/click details.
  - Drawing tools: berms, swales, ponds, streams, water flow directions, downspouts, spigots, drains, lawn, pasture, mulch, utilities (above-/underground), easements.
  - Boundary: Draw and confirm the parcel boundary here (required before any other drawings); one parcel per project; re-draw supported.
- Zones, Structures & Paths
  - Suggest drawing zones 0–5 as polygons.
  - Drawing/trace tools: houses, garages, sheds, playgrounds, foot paths, driveways, driving paths, patios, garden beds, trash cans, compost, fences, chicken coops.
- Plants & Animals
  - Suggest drawing/placing various plants, bushes, trees, and animals.

## In Scope
1) Map stack consolidation (Path B)
- Wire the custom overlay map into the project Map Planner page.
- Remove Mapbox Draw components/pages from this branch (another branch retains them).
- Ensure terrain/contours toggle is available and performant.

2) Address flow + parcel in Earthworks & Water
- After geocoding, show tabs; in Earthworks & Water present "Draw your parcel boundary" and enforce completion before other drawings.
- Distinct parcel styling; support re-draw; one parcel per project.

3) Persistence
- Save/load per-project design using Supabase `designs` (objects JSONB + coordinates).
- Include parcel polygon and object metadata.

4) NRCS/USDA soils (Layer 1)
- Server-side proxy endpoint to query NRCS soils for the parcel polygon/bbox.
- Frontend soil overlay with categorical coloring, hover/click details.
- Basic caching by project_id + parcel hash.

5) Tabs in Map Planner
- Tabs: Climate; Earthworks & Water; Zones, Structures & Paths; Plants & Animals.
- Tabs gate tools/overlays; persist last-selected tab per project.

## Out of Scope (v0.1)
- Water flow simulation; cut/fill; auto parcel from county APIs; 3D models; planting calendars; resource flow visualization.

## UX Flows (Condensed)
- New project → address → map centers → Earthworks & Water tab → draw parcel → soils/contours available → add objects via tabs → save → reload.
- Soil: toggle on Earthworks & Water → fetch via proxy → render polygons; hover/click for details.

## Data Model (Context)
- Supabase tables (context, not migrations):
  - projects(id, user_id, name, description, address, coordinates, created_at, updated_at)
  - designs(id (PK, FK auth.users), project_id (FK projects.id), objects jsonb, coordinates jsonb, updated_at)
  - questionnaire_responses(project_id UNIQUE, responses jsonb, created_at, updated_at)

## Milestones
- M1: Replace Mapbox Draw with custom map in Project Map Planner; remove Draw components/pages; expose contours/terrain toggle.
- M2: Parcel flow in Earthworks & Water, styling, one-per-project, re-draw.
- M3: Save/load per project (status UI, unsaved-changes indicator).
- M4: Soil proxy + overlay UI (hover/click details, caching).
- M5: Tabs bar + tab-scoped tools/overlays; Climate placeholder with WeatherSpark link.

## Risks & Assumptions
- Risk: NRCS endpoints variability; mitigate with server proxy + caching.
- Risk: Divergent map implementations; resolved by removing Mapbox Draw here.
- Assumption: Mapbox and Supabase env vars are configured; `designs/projects/questionnaire_responses` tables exist per context schema.
